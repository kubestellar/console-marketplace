# Postmortems

Completed postmortems for `kubestellar/console-marketplace` incidents live in this
directory, named `YYYY-MM-DD-<short-title>.md`.

Start from [`../postmortem-template.md`](../postmortem-template.md) — do not draft a
postmortem from scratch or from an ad-hoc format. See
[`../registry-incident-response.md#postmortem-template`](../registry-incident-response.md#postmortem-template)
for when a postmortem is required.

This directory is currently empty because no incident has reached the postmortem stage
yet.
